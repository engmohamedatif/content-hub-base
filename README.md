# Prestegzone

اسم المتجر: برستيج الاقصر (PRESTIGE LUXOR) مع استخدام الشعار المرفق وألوانه (الأخضر الداكن والذهبي).

التصنيفات والمنتجات:
عنايه بالشعر: صبغه، شامبو، بلسم، كريم شعر، جيل، زيت، سيروم، كريم فرد، حمام كريم.
عنايه بالجسم: شاور جيل، مرطب بشره، مخمريه، ماسك بشره، فازلين، كريم تفتيح، بودى سبلاش، لوف حمام.
مزيلات شعر: كريم ازاله، سبراى ازاله، سويت، شمع، مناديل شمع، جهاز شمع.
عنايه بالفم: فرش اسنان، معجون اسنان، مضمضه، معطر فم.
عنايه بالطفل: حفاضات، ببرونات، سكاتات، برفان اطفال، شامبو، زيت، شاور جيل، بودره تلك.
ورقيات: حفاضات كبار، حفاضات اطفال، فوط نسائيه، مناديل، مناديل مطبخ.
برفانات.
سبريهات.
ميك اب.
مبيدات حشريه.
معطرات جو.
متنوعات: سشوار، ماكنه حلاقه، مكواه شعر، جهاز شمع.

خطة التصميم والواجهة:
- تصميم متجر عربي متكامل باتجاه RTL متجاوب بالكامل مع الموبايل والتابلت والكمبيوتر.
- شريط علوي ورأس موقع مع الشعار، البحث السريع ("بتدور على إيه؟")، المفضلة، وسلة التسوق.
- شريط فئات للتنقل السريع وزر "كل الفئات".
- بانرات عروض ترويجية رئيسية متجاوبة.
- شبكة بطاقات الفئات بصور واضحة وعناوين قابلة للنقر.
- بطاقة منتج مميزة: صورة واضحة، الاسم، السعر قبل وبعد الخصم مع نسبة الخصم المحسوبة تلقائياً، والوصف المختصر الخاص بالبطاقة (الوصف الخارجي)، وزر الإضافة للسلة والمفضلة.
- صفحة تفاصيل لكل منتج تحتوي على: صور المنتج، الوصف الكامل المفصل (الوصف الداخلي)، السعر والخصم، الكمية المتبقية، وزر الشراء والإضافة للسلة.
- بدون تقسيط، مع التركيز على الوضوح والشفافية في الأسعار والشحن.
